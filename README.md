A股每日主线与情绪复盘 · 生成工作流
本 Skill 封装「零代码股票研究员」每日收盘后生成 A 股主线与情绪复盘单页 HTML 报告 的完整流程。核心资产：固定报告模板、配色规范、数据约定、取数流程与已验证经验（含 funddb 恐贪指数 CDP 取数法）。

同源辅助：数据源分工细节见 ~/.workbuddy/skills/ashare-sentiment-datasource/SKILL.md；市场情绪分析通用框架见工作区 skills/市场情绪分析/sentiment-analysis/SKILL.md（注意其含"北向资金信号"章节，与本 skill「北向永久剔除」约定冲突，不可照搬）。

〇、铁律（违反即废报告）
真实数据优先，凡不可得一律诚实留白或删除，绝不臆造。
此前 NeoData 曾虚构数据，项目已立"数据完整性"为第一原则。
自动生成产物（market-sentiment-*）常含 北向资金净卖出 字段且用 ECharts CDN——二者均违反约定，必须重建而非沿用。
涨红跌绿（中国 A 股惯例）：.up{color:红} .down{color:绿}。
信号语义层配色（与涨红跌绿同源）：偏多=红 / 风险=绿 / 中性=黄，见 references/conventions.md。.theme-card.real(偏多)/.ok 用红；.theme-card.trap(风险)/.warn 用绿；.theme-card.mid/.tag.m 用黄。注意：数值涨跌色与信号语义色是两套，只反转语义层、不动 .up/.down。
纯内联、零外部依赖：禁 ECharts/CDN/外链 <script src>。温度计用内联 <svg>。
标题统一单色：整标题 A股主线与情绪复盘 同色（无金色高亮 .accent）。
数值信号色（V3 视觉语言核心）：所有 Metric 卡 .v 数值自动继承父卡 line-* 类颜色——涨=红(line-red)/跌=绿(line-green)/中性=黄(line-gold)/无向=墨(line-ink)，左侧竖条、数值、标签三者同色（见 references/conventions.md 全局规则）。卡内双色数字（如涨停/跌停）用 .up(红)/.down(绿) span 覆盖，不受父卡影响。
量能独立规则：放量=红(偏多) / 缩量=绿(风险) / 持平=墨；缩量绝不可填中性黄（缩量是风险信号，非中性）。
Hero 半弧仪表盘 52° 数值固定深色 #1f2733（色带已用绿→黄→红表达温度区间），不随信号变色；指针按 data-temp 由模板内联 JS 自动对齐色带。
一、报告结构（4 模块 · 12 节，V3 视觉语言）
历史为 13 节（含龙虎榜·留白）。当用户要求"无数据字段去掉"时，删除龙虎榜留白节，后续顺移为 12 节，并归入 4 大模块：

① 市场总览（模块 m1）：1.1 大盘画像 / 1.2 外围市场 / 1.3 量能与资金
② 情绪量化（模块 m2）：2.1 短线情绪 / 2.2 市场广度 / 2.3 定量化情绪温度（竖温度计）
③ 主线资金（模块 m3）：3.1 板块强弱（Tab 强势/弱势）/ 3.2 题材热度 / 3.3 主力资金方向 / 3.4 涨停梯队
④ 决策输出（模块 m4）：4.1 主线识别 / 4.2 隔夜判断
各节内容语义与旧版一致（仅重新编号 + UI 排版升级）：

大盘画像（5 卡：上证/深证/创业板/科创综指/全市场成交额）
外围市场（取前一交易日美股收盘）
量能与资金（沪/深成交分拆卡 + 全市场成交额 + 平均股价 + 融资余额 T+1 卡）
短线情绪（涨停/跌停/炸板/封板率/连板晋级率 + 领跌深度解读）
市场广度（上涨/下跌/平盘 + 涨跌比 + 上涨占比）
定量化情绪温度（竖温度计 SVG + 7~8 个维度：涨停/跌停/涨跌比/成交额/PCR/恐慌指数等）
板块强弱（强势主线表 + 弱势掉队表）
题材热度（真主线 real / 轮动 mid / 退潮预警 trap 三类 theme-card）
主力资金方向（CPO反包吸金 / 算力共振 / 消费派发 三类 line-red/green 卡）
涨停梯队（连板明细：X板 / 断板警示 / 7天Y板 / 首板强催化）
主线识别（真主线 real / 轮动支线 mid / 退潮风险 trap 三类卡）
隔夜判断（偏多延续条件 ok + 退潮预警 warn + 免责声明 disc）
模板样例见 templates/daily-review.html（V3 视觉语言版，以 2026-08-14 报告为基底，含占位符 {{...}}；含粘性导航 scrollspy、Hero 半弧仪表盘、竖温度计、Metric 卡组件库、Tab 切换、折叠口径、返回顶部，全部纯内联 JS）。

二、数据源分工与取数流程
2.1 指数 / 广度 / 涨停跌停炸板连板 —— 通达信 TDX 连接器（首选真实源）
工具命名空间：mcp__tdx-connector__tdx_quotes / mcp__tdx-connector__tdx_screener（前置若未注册，先 ToolSearch 注册）。

指数收盘（setcode: 1=沪 / 0=深 / 2=北交所）：
上证 000001、深证 399001、创业板 399006、科创50 000688、科创综指 000681（用户要求用综指而非50）。
板块指数：平均股价 880003、昨日涨停 880863、昨日连板 880812（均 setcode=1）。
短线计数 tdx_screener(message, pageSize, pageNo, rang:"AG")：
涨停 / 跌停 / 炸板 / 连板 → 返回全市场计数 + 明细（含连续涨停天数、封单金额、涨停原因）。
封板率 = 涨停 / (涨停 + 炸板)；连板晋级率 = 昨日连板成分中续封数 / 成分总数（从 连板 明细的续封/断板拆分得出）。
市场广度 tdx_screener(message:"上涨"/"下跌"/"平盘") → 各返回家数；合计应约 5500。
TDX 面板可能显示 disconnected 但实测可用；tdx_quotes 的 code 只接受纯数字。

2.2 融资余额 / 外围 / 行业主力 —— 东方财富 + 公开聚合（交叉验证）
融资余额：T+1 滞后（填前一交易日，遇周末顺延）。
⚠️ 关键坑（已校正）：妙想(mx-finance-data)对"融资余额"全市场口径系统性低估约 1150 亿（如 8/7 妙想 24990 亿 vs 东财/公开实值 26142.62 亿）。一律以东财数据中心/公开聚合为准，妙想聚合值不可直接采用。
取数：东方财富数据中心两融页（data.eastmoney.com/rzrq，JS 动态，可用妙想/Web 抓取，或 WebSearch 公开聚合值）；填报"截至 X 日、沪+深"并标注日期、+额、连升天数。融券新规后趋零，两融≈融资，勿杜撰精确两融数。
外围（前一交易日美股）：WebSearch / 新华社·证券时报公开报道，取道指/纳指/标普涨跌幅 + 关键板块（存储/光通信）表现。标注"X/XX 美股收盘，为本交易日盘前最新参照"。
行业/概念精确主力净额：本项目无可靠全市场扫描源 → 第 7/9 节以"题材涨停聚类 + 封单金额"维度呈现，不编造具体净额（已在报告中明确说明）。
2.3 PCR 认沽认购比 —— 上交所期权日报（可得，标注滞后）
上证50ETF 认沽认购比，逐日公布（上交所期权之家 / 新浪财经期权每日行情）。
通常取最新可得日（如 8/7 的 0.68），标注"滞后"；勿自估。<1 看涨占优，>1 看空占优。
分位解读：<0.5 极度看多(反向看空) / 0.5–0.7 偏多 / 0.7–1.0 中性 / 1.0–1.5 偏空 / >1.5 极度看空(反向看多)。
2.4 恐慌指数（韭圈儿恐贪指数）—— funddb.cn + CDP 渲染取数
唯一可靠路径：浏览器 CDP 渲染读 DOM（静态层全部失效，见 references/funddb-cdp.md）。
用户开启浏览器远程调试（edge://inspect/#remote-debugging 勾选 Allow remote debugging）后，用 Web Access skill 的 cdp-proxy.mjs（localhost:3456）创建后台 tab 打开 https://www.funddb.cn/tool/fear，/eval 提取「恐惧贪婪指数表」：当前指数数值 + 更新时间 + 韭圈儿标签。
分位（韭圈儿标尺）：0–20 极度恐惧 / 20–40 恐惧 / 40–70 中立 / 70–90 贪婪 / 90+ 极度贪婪。
注意：该页更新慢，8/14 盘前最新值为 2026-08-13（33·中立）。取不到真实值时，第 6 节该行标"待补"并注明来源网址，不编造；待用户开启调试端口立即补入。
2.5 北向资金 —— 永久剔除
沪深港通自 2024-08-19 取消日频净买入/净卖出披露 → 全篇不含北向净额字段。
统一披露文案（全报告 4 处一致）：「北向资金净额自 2024-08-19 官方取消日频披露，本报告不含该字段」。
自动产物若含"北向净卖出 X 亿"字段，一律弃用。
三、执行流程（每次"完成今日复盘"）
确认交易日（当前日期 + 收盘后）。新建文件 A股主线与情绪复盘_YYYYMMDD.html。
并行 TDX 取数：指数(5~7个) + 涨停/跌停/炸板/连板 + 上涨/下跌/平盘（一次多发 DeferExecuteTool）。
东财/公开聚合：融资余额(T+1)、外围(前日美股)、行业主力(定性)。WebSearch 取外围与融资余额公开值。
恐贪指数：若用户已开调试端口 → CDP 取真实值；否则第 6 节标"待补"。
读取上一交易日模板（如 A股主线与情绪复盘_上一日.html）作为结构基底，替换为本交易日数据。模板为 V3 视觉语言：替换 {{...}} 占位符时，按真实方向设置每个 Metric 卡的 line-red/green/gold/ink 信号类（见铁律 6/7）；温度计/半弧仪表盘的 data-temp 填温度值，模板内联 JS 自动定位液柱与指针，无需手算坐标。
诚实修正闭环：若前日判断被今日数据证伪（如 8/13 判"CPO下跌中继"被 8/14 反包证伪），在对应节明确标注"前日判断误判/推翻重判"，不硬拗。
校验报告：Grep 确认 无 echarts|cdn|https?://|<script、无 北向净卖出、无 8/13(前日)残留数值、无 科创50(若用综指)、章节编号连续、配色规范（偏多红/风险绿/中性黄）。
present_files 呈现；写 .workbuddy/memory/YYYY-MM-DD.md 工作日志（数据校验结论 + 与模板差异 + 约定执行）。
