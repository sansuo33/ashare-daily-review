# 复盘报告 · 配色规范与数据约定速查

## 一、配色规范（两套色，互不混淆）

### A. 数值涨跌色（中国 A 股惯例）
- 涨 = **红** `.up{color:var(--red)}` `#e03131`；跌 = **绿** `.down{color:var(--green)}` `#0c9d6e`
- 背景变体 `.upbg` / `.downbg`（红/绿浅底）。

### B. 信号语义色（与涨红跌绿同源互补）
| 语义 | 含义 | 颜色 | CSS 类 |
|------|------|------|--------|
| 偏多 / 真主线 / 偏多延续 | 正面、可参与 | **红** `#e03131` | `.theme-card.real`、`.ok`、`.tag.t` |
| 风险 / 退潮 / 预警 | 负面、需回避 | **绿** `#0c9d6e` | `.theme-card.trap`、`.warn`、`.tag.w` |
| 中性 / 轮动支线 / 偏中性 | 观望 | **黄** `#e8a200` | `.theme-card.mid`、`.tag.m` |

> ⚠️ **关键陷阱**：报告内信号语义色（偏多红/风险绿）与数值涨跌色（涨红跌绿）**方向相反于直觉**（风险绿=跌绿、偏多红=涨红），二者是同一套红绿但语义不同。早期版本曾把 `.tag.t`/`.theme-card.real`/`.ok` 误设成绿色、把风险类设成红色（与规范反），已统一对调。改色时只动语义层（`real/ok/trap/warn/mid/tag.*`），**严禁动 `.up/.down` 数值色**。

### C. 其他
- 标题整标题同色（无金色 `.accent` 高亮）；报告内层级编号：模块 `①②③④` + 节 `1.1 / 1.2 … 4.2`。
- 温度计 SVG 渐变（统一 token）：底部绿(0°)→黄(50°)→红(100°)，三段 stop `#0c9d6e / #e8a200 / #e03131`，刻度 0/50/100；**Hero 半弧仪表盘与第 2.3 节竖温度计渐变必须完全一致**（同色 + 同 offset 比例）。
- 浅色主题：`--bg:#f4f6f9 --panel:#ffffff --panel2:#f0f3f7 --border:#e3e7ee --txt:#1f2733 --sub:#5b6675`。

### D. V3 视觉语言 · 数值信号色与组件（UI 回填版）
> 本部分对应 `templates/daily-review.html` V3。视觉语言锁定于 2026-08-17（设计稿 `A股情绪复盘_UI设计方案_20260817.html`）。

- **Metric 卡数值信号色（全局 CSS 规则）**：数值 `.v` 自动继承父卡 `line-*` 类，左侧竖条 / 数值 / 标签三者同色：
  - `line-red` → 红 `#e03131`（涨 / 偏多）
  - `line-green` → 绿 `#0c9d6e`（跌 / 风险）
  - `line-gold` → 黄 `#e8a200`（中性）
  - `line-ink` → 墨 `#2b3a55`（无方向信息，如"对A股映射""沪/深分拆""首板强催化"）
  - 卡内双色数字（如涨停/跌停）用 `.up`(红)/`.down`(绿) span 覆盖，不受父卡 `line-*` 影响。
- **量能独立规则**：放量 = `line-red` / 缩量 = `line-green` / 持平 = `line-ink`。**缩量绝不可填中性黄**。
- **Hero 半弧仪表盘** `52°` 数值固定深色 `#1f2733`（色带已表达温度区间）；指针与已点亮弧按 `data-temp` 由模板内联 JS 自动对齐，禁止手填错位坐标。
- **第 2.3 节竖温度计**：保留竖式；液柱与刻度标签随 `data-temp` 由 JS 定位（静态兜底 52°：fill y=130.4/h=109.6、num y=126）。
- **信号语义色（theme-card / tag / alert）**：偏多=红(`real`/`ok`/`tag.t`)、风险=绿(`trap`/`warn`/`tag.w`)、中性=黄(`mid`/`tag.m`)——与数值层同源但语义不同，改色只动语义层、严禁动 `.up/.down`。
- **交互**：粘性顶栏 + 模块 scrollspy 高亮；板块强弱 Tab 切换；数据口径 / 免责声明 `details` 折叠；返回顶部按钮。
- **可访问性**：`:focus-visible` 描边、`role/aria` 标注、`prefers-reduced-motion` 降级、正文对比度满足 AA。

## 二、数据约定速查

| 字段 | 约定 |
|------|------|
| 北向资金净额 | **永久剔除**（2024-08-19 官方取消日频披露）。统一文案：「北向资金净额自 2024-08-19 官方取消日频披露，本报告不含该字段」 |
| 融资余额 | **T+1 滞后**（填前一交易日，周末顺延）；**东财全市场口径为准**，妙想聚合值系统性低估 ~1150 亿不可直接采用；融券新规后趋零，两融≈融资 |
| 科创指数 | 用**科创综指（000681）**而非科创50（用户 8/14 起要求） |
| 恐慌指数 | 韭圈儿 funddb.cn，唯一可靠取数=`scripts/fetch_fear.js` 直解 API；取不到标"待补"不编造 |
| PCR | 上交所期权日报（可得），取最新可得日并标注"滞后" |
| 龙虎榜 | 无可靠源 → 按用户意见"无数据字段去掉"（删节）；不占位 |
| 行业精确主力净额 | 无全市场扫描源 → 以"题材涨停聚类+封单"维度呈现，不编造具体净额 |
| 自动产物 | market-sentiment-* 含北向字段+ECharts CDN → 违反约定，**必须重建** |

## 三、诚实原则

- 凡源不可得：留白或删节，**绝不编造**。
- 前日判断被今日数据证伪 → 在报告对应节明确标注"误判/推翻重判"，不硬拗（如 8/13 判 CPO 下跌中继被 8/14 反包证伪）。
- 交叉验证：TDX 真实值 + 东财/公开聚合；融资余额必用东财口径。
